# Projects

## 1. Driver Churn Prediction Using Ensemble Models

**Domain:** Predictive Analytics | Machine Learning | Classification

**Objective:**

Develop a machine learning solution to identify drivers who are likely to leave an organization, helping businesses understand churn patterns and improve driver retention strategies.

**What I Implemented:**

- Performed exploratory data analysis to understand driver behaviour and identify important churn indicators.
- Engineered relevant features to improve model performance.
- Handled class imbalance using SMOTE.
- Implemented and compared XGBoost and Random Forest classification models.
- Applied GridSearchCV for hyperparameter optimization.
- Identified important churn indicators, including Quarterly Rating and Total Business Value.

**Results:**

- Achieved 94% model accuracy.
- Achieved 0.97 ROC-AUC.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Random Forest, SMOTE, GridSearchCV.

**Project Repository:** [Driver Churn Prediction](https://github.com/Shrivas20/Ensemble-ML-OLA)

## 2. Time Series Forecasting for Ad Placement Optimization

**Domain:** Time Series Analysis | Predictive Modelling

**Objective:**

Forecast Wikipedia page views to support data-driven advertisement placement and traffic prediction.

**What I Implemented:**

- Explored historical page-view data to identify trends and seasonal patterns.
- Implemented ARIMA and SARIMAX time series forecasting models.
- Applied Prophet to capture trends and seasonal variations.
- Incorporated external variables such as marketing events to improve forecasting.
- Compared forecasting performance using Mean Absolute Percentage Error (MAPE).

**Results:**

- Achieved approximately 5% MAPE using Prophet with exogenous variables.

**Technologies:** Python, Pandas, NumPy, ARIMA, SARIMAX, Prophet, Time Series Analysis.

**Project Repository:** [Time Series Forecasting](https://github.com/Shrivas20/TimeSeries-Adease)

## 4. Hypothesis Testing with YULU Bike Rental Data

**Domain:** Statistical Analysis | Hypothesis Testing | Business Analytics

**Objective:**

Understand the factors influencing bike rental demand and evaluate the impact of weather conditions, working days and holidays on rental behaviour.

**What I Implemented:**

- Conducted exploratory data analysis to identify seasonal and weather-related demand patterns.
- Formulated statistical hypotheses to evaluate relationships between business factors and rental demand.
- Performed statistical tests to measure the influence of working days, holidays and weather conditions.
- Interpreted statistical results to identify significant and insignificant factors affecting rental demand.

**Key Findings:**

- Weather conditions and seasonal changes showed significant influences on rental demand.
- Holidays and non-holiday differences showed negligible impact in the analysis.

**Technologies:** Python, Pandas, NumPy, SciPy, Statistical Testing, Hypothesis Testing, EDA.

**Project Repository:** [YULU Hypothesis Testing](https://github.com/Shrivas20/HypothesisTesting_YULU)
